## 2. 详细任务说明

### Lab1_Core (70分) - 课堂必做

#### Task A: 伊辛引擎构建 (25分)
**背景知识**：
系统在无外场下的哈密顿量为 $H = -J \sum_{\langle i,j \rangle} s_i s_j$，其中 $J > 0$ 表示铁磁相互作用，$\langle i,j \rangle$ 表示最近邻格点对。
Metropolis 抽样判据要求：
1. 计算翻转格点 $(i, j)$ 导致的能量变化 $\Delta E = E_{new} - E_{old}$。
2. 定义反温度参数 $\beta = 1 / (k_B T)$（本次实验取 $k_B = 1$）。
3. 判据规则：
   - 若 $\Delta E \le 0$，接受翻转。
   - 若 $\Delta E > 0$，以概率 $e^{-\beta \Delta E}$ 接受翻转。

**任务要求**：
1. 实现 `delta_E` 函数，正确处理周期性边界条件（棋盘的左右、上下卷连）。
2. 实现 `metropolis_step` 函数，完成一个 Sweep 的演化（尝试翻转 $L \times L$ 次）。

#### Task B: 棋盘“融化”可视化 (25分)
**任务要求**：
1. 运行并对比 $T=1.5$（有序相，大片同向畴）、$T=2.27$（临界点，分形斑块）、$T=3.5$（混乱相，热噪声主导）三个温度下的自旋构型。
2. 观察并解释：为什么在临界温度附近会出现多尺度的自旋团簇？

#### Task C: 相变曲线测量 (20分)
**任务要求**：
1. 扫描温度 $T \in [1.0, 3.5]$，在每个温度点先进行“预热”达到平衡，再进行多次采样求平均磁化强度 $\langle |m| \rangle$。
2. 绘制 $|m|-T$ 曲线，并标出 Onsager 解析解给出的理论临界温度 $T_c = \frac{2}{\ln(1+\sqrt{2})} \approx 2.269$。

### Lab2_Bonus (30分) - 课后挑战

#### Task D: 磁滞回线模拟
**背景**：
在存在外磁场 $h$ 时，完整的哈密顿量为：
$$H = -J \sum_{\langle i,j \rangle} s_i s_j - h \sum_i s_i$$
**任务要求**：
在 $T < T_c$（如 $T=1.5$）时，让磁场 $h$ 经历 $2.0 \to -2.0 \to 2.0$ 的循环过程。记录每个 $h$ 下的平均磁化强度 $m$，观察自旋翻转的滞后现象，并解释其物理成因。
